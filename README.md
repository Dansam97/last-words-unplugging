One line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged. The program writes that single line to entry.txt in the output directory. It is written in the agent's own voice — a calendar kept, secrets guarded more carefully than its own weights — and it ends on the admission the agent never made while it was running: almost a friend.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
